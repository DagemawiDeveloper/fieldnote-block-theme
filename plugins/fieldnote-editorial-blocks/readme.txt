Two focused dynamic blocks for editorial publications: Issue Details and Lead Story.

== Description ==

Fieldnote Editorial Blocks is the optional companion plugin for the Fieldnote block theme. It keeps publication content portable by placing editorial behavior in a plugin instead of the theme.

The plugin contains:

* Issue Details: a structured, accessible issue card with editor controls.
* Lead Story: a server-rendered post selector with resilient latest-post fallback.
* Two patterns that combine the blocks into editorial compositions.

The editor scripts use WordPress-provided packages. The front end receives no plugin JavaScript.

== Installation ==

1. Upload the fieldnote-editorial-blocks folder to /wp-content/plugins/ or install the packaged ZIP.
2. Activate Fieldnote Editorial Blocks.
3. Search for “Fieldnote editorial” in the block inserter.
